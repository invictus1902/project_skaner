# Учёт рабочего времени

Киоск для компьютера со сканером штрихкодов или QR, монитором и динамиками.
Сотрудник подносит бейдж: первый скан за смену — приход, повторный — уход.
Имя и время крупно показываются на экране и произносятся голосом Windows.

## Запуск

На компьютере с Windows 10:

```bat
py -3.13 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python main.py
```

Или дважды щёлкнуть `start.bat`, если окружение уже установлено.

Пароль админки по умолчанию: `admin`. Его нужно сменить.
Админка открывается кнопкой «Админ» или клавишей F12.
Полный экран переключается клавишей F11.

На Windows 7 и 8 нужен Python 3.8.10 — это последняя версия Python для этих систем.
Код программы с ней совместим. Голос берётся из установленных голосов Windows.
Для русской речи нужен русский голос, обычно Microsoft Irina.

## Сканер

Подходит обычный USB-сканер, который вводит код как клавиатура и нажимает Enter.
Отдельный драйвер не нужен. Для QR с буквами на этом компьютере должна быть
включена английская раскладка: русская раскладка подменяет латинские буквы.
Бейджи только из цифр от раскладки не зависят.

Если купленный сканер работает через COM-порт, это включается в админке.

## Сервер

В админке два адреса: откуда брать сотрудников и куда слать отметки.
Кнопки «Рабочий сервер» и «Локальный сервер» заполняют оба.
Окно «Смены» показывает людей с сайта. Если хостинг закрыт страницей входа,
список берётся из той же базы, что и сайт. Ключ этой базы в репозиторий не входит.
Вход профилем администратора нужен для отметок прихода и ухода, не для списка людей.
